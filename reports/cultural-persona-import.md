## 人设内容与来源边界

每个数据包包含身份、历史背景、领域、文化及语言标签、开场白、3 个建议问题、系统设定、表达规则、知识边界、关系和记忆规则、价值取向、4 个模拟对话示例、风险约束和来源标识。

这是基础模拟人设 v1。身份、年表和来源沿用已核对目录；说话方式、价值取向和示例是编辑创作，不能冒充本人引文、私人记忆或经逐人原典研究确认的心理特征。现有四份独立人设优先于生成包。

数据位于 `apps/api/src/db/data/global-cultural-personas.json`。生成器按人物的独立话题与不同领域的表达策略生成完整字段；`sourceNotes` 保留 QID、地区、语言、来源、资格和创作状态。

## 导入和读取行为

- `npm run personas:build-cultural` 从目录生成数据包；`npm run db:import-cultural` 执行导入。
- 整批事务，异常回滚；稳定 slug/QID 防重；内容哈希相同则跳过；后续内容修订新增版本，不覆盖旧版本。
- 本地 PGlite 导入必须在 API 停止、数据库没有其他写入进程时运行。不能同时打开同一个持久化目录。
- 导入前的数据库备份：`outputs/db-backups/before-cultural-import-20260910-212621/.pglite-data`。
- 列表新增 `offset` / `hasMore` / `total`，前端逐页加载。检索不再预先截断前 200 条，单页最多 100 条。
- 本地前端 `.env.local` 已设置 API 地址为 `http://127.0.0.1:4000`。若浏览器曾手动选择 Demo，仍需使用界面的模式切换进入 API。
