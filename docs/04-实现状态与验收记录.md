## 1. 工程形态

已落地 TypeScript npm workspaces monorepo：

- `apps/api`：Fastify 模块化 API（等价于技术文档 NestJS+Fastify 的职责边界；当前为更轻量的 Fastify 直连实现）

- `apps/mobile`：Expo Router 移动端核心流程
- `packages/*`：contracts / domain / model-gateway / prompts / ui

数据库：Drizzle + PostgreSQL 方言；本地默认 PGlite；可选 docker compose Postgres。

## 4. 已知技术决策

1. API 使用 Fastify 而不是 NestJS，模块边界按 Auth / Persona / Conversation / Memory / Models 划分。
2. Ollama 人格聊天走原生 `/api/chat` 并默认 `think:false`，避免 qwen3.5 把 token 耗在 reasoning 导致正文为空。
3. DeepSeek 日常聊天 `thinking.disabled`；`reasoning_content` / `reasoning` 不作为角色台词。
4. 无 Docker 时默认 `USE_PGLITE=true`。
