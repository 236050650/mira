# MIRA 开发文档索引

本目录用于把当前高保真网页 Demo 转化为可开发、可测试、可验收的跨平台人格模拟器产品。

## 阅读顺序

1. [产品需求规格书](./01-产品需求规格书.md)：明确产品范围、用户流程、功能优先级和完成标准。
2. [技术设计文档](./02-技术设计文档.md)：明确客户端、后端、模型网关、数据结构、接口与低额度开发方案。
3. [最终验收方案](./03-最终验收方案.md)：开发者自测、提测与最终验收的唯一依据。

## 当前基线

- 视觉与交互参考：本项目 `app/` 中的网页 Demo。
- 默认视觉：浅色主题，可切换深色主题。
- 内容范围：中国历史人物、思想家、军事家、动漫角色、原创角色。
- 远程模型：DeepSeek OpenAI 兼容接口。
- 本地模型：Ollama OpenAI 兼容接口。
- 当前本机默认本地模型：`qwen3.5:latest`。
- 当前 Demo 的注册、登录、消息和聊天均为模拟数据；正式开发必须按文档实现真实后端。

## 文档规则

- “必须”表示 P0 验收项，未通过不得判定项目完成。
- “应当”表示 P1 验收项，除非有书面变更，否则也应完成。
- “可以”表示 P2 增强项，不阻塞第一版交付。
- 如需求与当前网页 Demo 冲突，以本目录文档为功能准则，以网页 Demo 为视觉准则。
- 所有需求变更必须同时修改产品需求、技术设计和验收用例，避免三份文档失配。
